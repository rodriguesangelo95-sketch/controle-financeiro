# Controle Financeiro

Aplicação web criada para ajudar no registro e organização de receitas e despesas pessoais. O projeto ainda está em desenvolvimento.

## Objetivo

Criar um sistema simples onde o usuário possa cadastrar suas receitas e despesas e consultar um resumo das movimentações financeiras.

## Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Resumo financeiro
- Exibição das últimas movimentações
- Armazenamento das informações em banco de dados

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO

## Principal desafio

O principal desafio foi criar a conexão entre a aplicação e o banco de dados. Para entender esse processo, pesquisei vídeos e materiais sobre PHP, PDO e MySQL.

## Aprendizados

Durante o desenvolvimento pratiquei a criação de formulários, conexão com banco de dados, envio de informações e organização dos arquivos do projeto. Também aprendi a identificar erros e buscar soluções para continuar o desenvolvimento.

## Situação do projeto

Projeto em desenvolvimento. Algumas funções ainda serão melhoradas e novas ferramentas poderão ser adicionadas.
